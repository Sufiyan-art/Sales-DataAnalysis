# Sales Data Analysis using Power BI

## Project Overview

This project analyzes sales performance using Power BI. The dataset was cleaned and transformed before creating interactive visualizations and DAX measures.

## Data Cleaning

* Removed duplicate Order IDs
* Checked missing customer values
* Created Missing Customer Status column
* Verified data types
* Handled missing quantity values

## DAX Measures

* Total Sales
* Total Orders
* Average Sales
* Total Quantity

## Insights

* Top Customers
* Sales by Region
* Highest Sales by Category
* Regional Performance Analysis

## Tools Used

* Microsoft Excel
* Power BI Desktop
* DAX
